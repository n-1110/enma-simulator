閻魔大王シミュレータ（仮） 試作版 0.3.18

■ 起動方法
このゲームは画面ごとにHTMLファイルを分けています。画面間でlocalStorageを共有するため、index.htmlを直接ダブルクリックせず、ローカルサーバー経由で起動してください。

1. ZIPを展開します。
2. VS Codeで enma_simulator_v0_3_18 フォルダを開きます。
3. 拡張機能「Live Server」をインストールします。
4. index.htmlを右クリックし、「Open with Live Server」を選びます。
5. ブラウザのアドレスが http://127.0.0.1:5500/ などになっていることを確認します。

※外部ライブラリ、外部API、サーバーへのデータ送信は使用していません。
※セーブデータはブラウザのlocalStorageに保存されます。同じブラウザ・同じサイトで利用してください。
※0.3.18では保存キーを新しくしています。0.3.17以前のセーブデータ・行いの記録・設定は読み込みません。以前のデータはブラウザ内に残りますが、ゲームの動作には使われません。「全てのデータを削除」を実行すると、本作の旧版を含む保存データも削除されます。

■ 後から変更しやすい箇所

1. 行いを追加・変更する
   js/data.jsの以下の配列を編集します。
   - ORIGINAL_DEEDS：オリジナルの行い
   - NEUTRAL_DEEDS：善行・日常の行動
   - ANONYMOUS_VIDEO_DEEDS：名前なし動画ネタ枠
   - NAMED_NPC_TEMPLATES：名前付き動画由来NPCと固有の行い

   各行いの主な項目：
   - id：他の行いと重複しない識別子
   - name：行いの短い見出し
   - desc：行いの説明
   - targetHell：妥当な行き先。0=天国、1～8=第一～第八地獄

2. ゲームバランスを変更する
   js/config.jsを編集します。期ごとの裁判数、地獄ごとの基本滞在期数、地獄の刑期上限・収容人数、現世帰還者のゲームオーバー人数、NPC出現率、判決ペナルティなどを設定できます。

3. 台詞・獄卒イベントを追加・変更する
   js/content.jsを編集します。亡者の反応、閻魔AIのコメント、獄卒イベントの相談者・会話・選択肢・リアクション・求心力や収容余力への効果を設定できます。

4. 判決の評価ルールを変更する
   js/game.jsのevaluate()を編集します。行いの妥当な行き先との差と、刑期の評価基準を管理しています。

5. 判決履歴・地獄の様子を変更する
   判決履歴の表示内容や、亡者の表示数はjs/ui.js、地獄の背景・亡者の配置・動きはcss/style.cssで変更できます。現在の地獄背景は仮のCSS表現です。

6. 画面の見た目を変更する
   css/style.cssを編集します。各画面の専用スタイルは、該当する画面名のコメント付近を確認してください。

7. ドット絵素材を差し替える
   assets/judge.svg       閻魔大王
   assets/enma-ai.svg     閻魔AIのアイコン
   assets/soul.svg        一般亡者
   assets/named-soul.svg  特別NPC
   assets/ogre.svg        獄卒イベントの相談者
   assets/court-bg.svg    裁判画面の背景
   assets/title-bg.svg    タイトル画面の背景
   同名ファイルを差し替えるか、HTML/CSS内の画像パスを変更してください。

■ デバッグモード
- キーボードで「ENMADEBUG」と入力すると、画面遷移用メニューが開きます。
- タイトル、就任手続き、裁判、獄卒イベント、振り返り、クリア、ゲームオーバーの各画面へ移動できます。
- クリア画面はプレビュー表示です。プレビューだけでエンディング記録は更新されません。ゲームオーバー画面は、実際の条件を満たしている場合は実際の結果を優先して表示します。
- デバッグ中も同じコマンドでメニューを再表示できます。終了するときはメニューの「デバッグモードを終了」を選んでください。

■ セーブデータ
- ゲーム進行はモードごとに手動3枠とオートセーブ1枠です。現在利用できるのはノーマルモードです。サンドボックスモードは未実装です。
- 行いの記録はモードごとに保存します。
- 初回の注意書きはモード共通で1回だけ表示します。
- エンディングの発見状況はモード共通で記録します。
- 保存先はjs/storage.jsで管理しています。仕様を大きく変更した場合は、新しい保存キーを使ってください。旧版データの変換・読み込みは行いません。
